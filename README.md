## ▶️ Como Executar

1. Certifique-se de ter o .NET instalado
   👉 [https://dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)

2. Clone este repositório:

```bash id="9ppq2v"
git clone https://github.com/seu-usuario/lista-exercicios-02.git
```

3. Acesse a pasta do exercício desejado:

```bash id="1d95mp"
cd lista-exercicios-02/Lista2ex1
```

4. Execute o projeto:

```bash id="lpjoxl"
dotnet run
```

> 💡 Dica: Se estiver usando Visual Studio, abra a pasta do exercício e execute normalmente.

## ✍️ Exemplos de Exercícios

* Verificar se um número é par ou ímpar
* Calcular média e verificar aprovação ou reprovação
* Identificar o maior entre dois ou três números
* Verificar se um valor é positivo, negativo ou zero
* Resolver problemas utilizando múltiplas condições (`if-else if`)
